### CSS I
- Desde CSS How To, recorrer todo CSS, ver box model, estilos basicos
- Tarea sugerida para practicar, arranquen a clonar o a armar una pagina web y estilen
    - background-color
    - color
    - font-family
    - border
    - width, height

#### HTML I
- Repasar HTML hasta Elementos en Bloque y elementos en linea
- Ejercicio sugerido: Armar una pagina con una receta. Usen todas las etiquetas HTML que necesiten

- Prox clase haremos un repaso de como armar y organizar bien el HTML de nuestra web y continuaremos desde ahi hasta html forms incluido
- Continuar desde clases e ids!
